# Literasi Digital - Website WordPress

Tugas mata kuliah Literasi Digital.

## Teknologi
- WordPress
- PHP
- Apache (XAMPP)
- MariaDB

## Database
Database diekspor di folder db/database.sql.

## Cara Menjalankan
1. Pastikan folder website berada di C:\xampp.apk\htdocs\literasi.
2. Buat database wp_literasi.
3. Impor file db/database.sql.
4. Salin wp-config-sample.php menjadi wp-config.php.
5. Isi konfigurasi database.
6. Buka http://localhost/literasi.

## topik situs
Website Literasi Digital

## Halaman Website
- Beranda: halaman utama website.
- Blog: halaman untuk menampilkan artikel atau tulisan.
- Tentang Saya: halaman berisi informasi tentang pembuat website.
- Kontak Saya: halaman untuk informasi atau menghubungi pembuat website.
